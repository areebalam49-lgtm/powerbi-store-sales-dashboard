# Store Sales & Inventory Dashboard (Power BI)

A 3-page Power BI dashboard for a small general store: sales trends, product and supplier performance, and low-stock alerts.
It builds on my [SQL inventory database project](#) (add link): the same data, taken from SQL into a Power BI model.

![Overview](screenshots/overview.png)

## Business questions

1. How is revenue trending month to month, and which days of the week are busiest?
2. Which products and categories bring in the most revenue and margin?
3. Which suppliers deliver late, and how often?
4. Which items are below their reorder level right now, and how many days of stock are left?

## Tools and skills

- **Power Query (M):** CSV import, type fixing, text cleaning, de-duplication, merging bills into sale lines, calculated columns
- **Data modelling:** star schema (2 fact tables, 3 dimensions), one-to-many single-direction relationships, a marked date table
- **DAX:** CALCULATE, filter context, ALL, DATEADD, DATESINPERIOD, RANKX, running totals, MoM %, share of total
- **Report design:** KPI cards, synced slicers, drill-through, bookmarks, conditional formatting, tooltips
- **SQL:** export and validation queries (SQLite)

## Data model

Star schema, described in detail in [`docs/data_model.md`](docs/data_model.md).

| Table | Rows (sample data) |
|---|---|
| FactSales | ~94,000 sale lines |
| FactPurchases | ~1,800 purchase orders |
| DimProduct | 69 products across 8 categories |
| DimSupplier | 8 suppliers |
| DimDate | 12 months (Nov 2025 – Oct 2026) |

## Report pages

| Page | What it shows |
|---|---|
| Overview | Revenue, margin %, bills, average bill value; monthly trend with 3-month average; weekday pattern; payment mix |
| Products & Suppliers | Top 10 products, category → product matrix with margin, supplier delay and on-time % |
| Product Detail (drill-through) | One product's monthly sales, stock and purchase history |
| Stock Alerts | Items below reorder level with days of cover; bookmark toggle between all items and alerts only |

## How to run it

1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free, Windows).
2. Clone this repo.
3. In Power BI: **Home → Transform data → Manage Parameters → New**, create a text parameter `DataFolder` = full path to `data\sample\` (with the trailing `\`).
4. Add each query from `powerquery/queries.pq` (Blank Query → Advanced Editor), then **Close & Apply**.
5. Create the date table and measures from the `dax/` folder, then set relationships as in `docs/data_model.md`.
6. Build the pages from `docs/report_layout.md`.
7. Check the numbers: `python scripts/validate_sample.py` should match your cards.

To use your own store data: run `sqlite3 store.db < sql/export_to_csv.sql`, point `DataFolder` to `data\`, and refresh.

## About the data

`data/sample/` contains **synthetic data** generated by `scripts/generate_sample_data.py`. It has the same structure as a
small store database (about 33,000 bills over 12 months), so the project can be shared publicly without exposing
real business data. Swap in your own export to analyse a real store.
